ゲーム『漢末万人敵』

本ゲームは、いかなる個人情報も収集・送信・共有しません。

  • ゲームの進行状況と設定はお使いの端末にのみ保存され、アプリを削除すると一緒に削除されます。
  • 本ゲームにはアカウント、広告、アクセス解析・トラッキングはなく、インターネットにも接続しません。
  • ゲーム内に第三者の広告や解析用 SDK は含まれていません。
  • 購入やダウンロードに関するデータは、各ストア（Apple、Google、Valve など）がそれぞれのプライバシーポリシーに基づいて取り扱います。これらのデータが当方を経由することはありません。

本サイトについて

  • 本サイトは Cookie を使用せず、トラッキングやアクセス解析も行いません。フォントや画像は本サイトから配信しており、第三者から読み込みません。
  • 選択した表示言語は、お使いのブラウザのローカルストレージ（localStorage）にのみ保存され、当方には送信されません。
  • 本サイトは GitHub Pages でホストされています。GitHub はセキュリティと運用のために接続情報（IP アドレスなど）を記録する場合があります。詳しくは GitHub のプライバシーステートメントをご覧ください。
  • Discord へのリンクをクリックすると Discord のサイトに移動し、Discord 独自のプライバシーポリシーが適用されます。

お送りいただいたメール

メールでお問い合わせいただいた場合、メールアドレスと内容は返信のためにのみ使用し、それ以外の目的に使ったり第三者に提供したりすることはありません。

子どものプライバシー

当方は個人情報を一切収集しないため、子どもの個人情報も収集しません。
